## 📌 Descrição do projeto

Neste projeto, atuo como assistente de análise de dados na empresa fictícia Telecom X, que enfrenta um alto índice de cancelamento de clientes (Churn). O objetivo principal é entender quais fatores influenciam a evasão de clientes e gerar insights que apoiem decisões estratégicas do negócio.

O desafio envolve a coleta, tratamento e análise de dados utilizando Python e suas principais bibliotecas, com foco em preparar uma base sólida para que a equipe de Data Science possa avançar posteriormente para a criação de modelos preditivos e estratégias de retenção de clientes.

## ✍️ Metodologia

### O que foi praticado neste projeto:

* Importação e manipulação de dados a partir de uma **API**
* Aplicação do processo de **ETL** (_Extração, Transformação e Carga_)
* Criação de **visualizações de dados** para identificação de padrões e tendências
* Realização de uma **Análise Exploratória de Dados (EDA)** 
* Geração de **insights relevantes** para apoiar a redução do Churn

## 🛠️ Abrir e rodar o projeto

### Com Git:

1. Clone este repositório:

```
git clone https://github.com/michellyaanjos/telecom-x.git
```

2. Instale os pacotes necessários:

```
pip install -r requirements.txt
```

3. Execute o notebook:

```
jupyter notebook TelecomX.ipynb
```

### Com Google Colab:

1. Acesse: https://colab.research.google.com

2. Clique em **File** → **Open notebook**

3. Vá na aba **GitHub**

4. Cole a URL do repositório abaixo e pressione Enter.

```
https://github.com/michellyaanjos/telecom-x.git
```

5. Selecione o arquivo .ipynb desejado e clique em **Open**.
